# 함께 짜는 시간표 — Cloudflare 배포 안내

Cloudflare 무료 플랜만으로 동작합니다(Workers + Durable Objects). 신용카드는 필요 없습니다.

## 들어 있는 파일
```
wrangler.jsonc     Cloudflare 설정 (이름, 저장소 연결)
package.json       배포 도구(wrangler) 목록
src/worker.js      서버: 인증코드 확인, 저장, 실시간 알림
public/index.html  화면 (프로그램 전체)
```

## 1. 준비 (한 번만)
1. https://dash.cloudflare.com 에서 무료 계정을 만듭니다.
2. PC에 **Node.js**(https://nodejs.org, LTS)를 설치합니다.
3. 이 폴더를 압축 해제한 곳에서 명령 프롬프트(터미널)를 열고:
   ```
   npm install
   npx wrangler login        ← 브라우저가 열리면 '허용'
   ```

## 2. 배포
```
npx wrangler deploy
```
끝나면 `https://school-timetable.<내 계정 이름>.workers.dev` 주소가 나옵니다. 이 주소를 선생님들께 알려 주면 됩니다.
- 처음 배포할 때 workers.dev 하위 이름(subdomain)을 정하라는 안내가 나오면 원하는 영문 이름을 넣습니다.
- 이름을 바꾸려면 `wrangler.jsonc`의 `"name"`을 바꾼 뒤 다시 배포하세요.
- 고친 뒤에는 `npx wrangler deploy`를 다시 하면 됩니다. 저장된 시간표는 그대로 남습니다.

### 내 도메인으로 쓰기 (선택)
Cloudflare에 등록된 도메인이 있으면 대시보드 → Workers & Pages → school-timetable → 설정 → **도메인 및 경로** → 사용자 지정 도메인 추가 (예: `timetable.우리학교.app`).

### 최고관리자 코드 정하기 (꼭 한 번)
새 학교는 **최고관리자 코드**를 아는 사람만 만들 수 있습니다. 이 코드는 GitHub에 올리지 않고 Cloudflare에 비밀값으로 넣습니다.
1. Cloudflare 대시보드 → Workers & Pages → **school-timetable** → 설정(Settings) → **변수 및 비밀(Variables and Secrets)** → 추가
2. 유형 **비밀(Secret)**, 이름 `SUPER_CODE`, 값: 영문·숫자 8자 이상 (예: `JUNE2026TT`) → 저장(배포)
   - 터미널에서는 `npx wrangler secret put SUPER_CODE`
3. 새 학교 만들기 창의 **최고관리자 코드** 칸에 이 값을 넣습니다. 대소문자는 구분하지 않습니다.
- 정하지 않으면 아무도 새 학교를 만들 수 없습니다. 이미 만든 학교는 그대로 쓸 수 있습니다.
- 한 곳(IP)에서 30분에 5번 틀리면 잠시 막힙니다.

### 최고관리자 창 (`주소/#/super`)
첫 화면 맨 아래 **최고관리자** → 최고관리자 코드(SUPER_CODE)로 들어갑니다.
- 모든 학교 목록(검색에 숨긴 학교 포함), **＋ 새 학교 만들기**
- 학교마다 **기본설정 열기**: 학교관리자 코드를 몰라도 그 학교 기본설정에 들어갑니다.
- 학교마다 **학교관리자 코드 다시 정하기**: 학교관리자가 코드를 잊었을 때 새로 정해 알려 줍니다(예전 코드로 들어와 있던 기기는 끊김). 코드는 암호화해 저장하므로 예전 코드는 볼 수 없습니다.
- 학교관리자는 그 코드로 자기 학교 기본설정에만 들어갑니다.

## 3. 학교에서 쓰는 순서
1. **최고관리자**: 배포한 주소 → 새 학교 만들기 (학교 이름·학교 코드·관리자 코드 6자 이상·**최고관리자 코드**)
   - **학교급**: 초등학교(1~6학년) · 중학교(1~3학년) · 고등학교(1~3학년) · 기타(1~6학년). 학교급에 맞는 기본 과목(중학교 공통·선택 교과, 고등학교 2022 개정 공통·선택 과목 예시)과 시정(초 40분 · 중 45분 · 고 50분)이 들어갑니다.
   - 학교를 만들면 **처음 설정 안내**가 뜹니다: 기본 정보 → 학급 → 시정표 → 과목 → 장소 → 선생님 → 교과전담 배정 순서로 '저장하고 다음'을 누르며 넣습니다. 나중에 기본설정 → 관리 → '설정 안내 다시 보기'로 다시 볼 수 있습니다.
   - 학교 이름 옆에 지금 단계가 크게 보입니다: **1단계** 교과전담·강사 입력(새 학교는 여기서 시작) / **2단계** 담임 입력. 기본설정 → 기본 정보 → 입력 순서에서 바꿉니다.
   - 선생님들은 첫 화면 **학교 찾기**에 학교 이름 일부(예: 한빛)나 학교 코드를 넣어 들어옵니다. 검색에 안 보이게 하려면 기본설정 → 기본 정보 → '첫 화면 학교 검색에 보이기'를 끄세요.
2. 기본설정 → **학급**: 학년별 학급 수, **학년·학급 이름**(예: 사랑반·희망반 — 비우면 1반·2반), 수업하는 요일. 학교급 '기타'는 학년을 더하거나 뺄 수 있습니다(최대 12)
   - 학급 수를 정하면 학급마다 **담임 자리**가 저절로 생깁니다(선생님 메뉴에서 이름만 넣기). 이름을 넣었거나 시간표를 넣은 담임이 있는 학급을 줄이거나 학년을 빼면 확인창이 뜨고, 확인하면 그 담임도 함께 지워집니다. / **시정표**: 교시 수·시각·점심 위치·점심 시작·끝 시각, **요일별 교시**(격자 칸을 눌러 켜고 끄기)
   - 시정표에 **🍚 점심 · 중간놀이 · 다른 쉬는 시간**을 넣고 ⠿ 를 끌어 자리를 옮깁니다. 옮기면 교시 시각이 저절로 다시 맞춰집니다(점심 위치·교시 수·쉬는 시간 길이를 바꿔도). '⚡ 자동으로 만들기'는 시정표 메뉴 위에 하나로, 모든 시정표에 같은 수업·쉬는 시간을 적용합니다. 그 안의 **🤸 중간놀이**로 ○교시 뒤 ○분을 모든 시정표 또는 학년군 하나에 넣거나 뺍니다. PC에서는 시정표와 요일별 교시가 나란히, 휴대폰에서는 위아래로 보입니다.
   - 과목마다 **주 ○시간**(주당 기본 시수)을 넣으면 담임 자동 생성에 미리 들어가고, 학년군 머리에 학년별 합계/한 주 수업 칸이 실시간으로 보입니다(맞으면 초록·모자라면 주황·넘으면 빨강). 장소 메뉴에서는 장소마다 배정된 수업 시간이 보입니다.
   - 시정표 **⚡ 자동으로 만들기**: 1교시 시작·수업 ○분·쉬는 시간 ○분·점심 ○분을 넣고 '시정표 만들기' → 점심시간 위치 교시 뒤에 점심을 넣어 시각을 채웁니다. 표는 1교시 → … → 🍚점심(색) → … 순서로 보입니다.
   - **과목**은 학년군(1·2 / 3·4 / 5·6) 아래에 묶여 있고 눌러서 펼치고 접습니다. '학년군 추가·삭제·순서 바꾸기'에서 학년군 이름·학년·순서를 바꿉니다.
   - 과목마다 **교담** 체크 → 교담 선생님·주당 시수를 고르면 '교과전담 배정'에 학년별로 바로 들어갑니다.
   - **선생님** 직위: 담임교사·교과전담·스포츠강사·영어전문회화강사, 필요하면 직위를 더 만들 수 있습니다.
   - 관리 → **시간표 지우기**: 학급·학년·선생님·교과전담·강사·전체 (지울 시간 수를 먼저 보여 줌)
   - 1~2·3~4·5~6학년처럼 점심시간이 다르면 시정표를 '복사해서 새 시정표'로 늘리고 학년마다 고릅니다.
   - 초등학교는 처음부터 학년군 시정표 3개가 만들어집니다(2026 통합 시정표 기준): 1·2학년·3·4학년은 3교시 뒤 점심 11:30~12:10·4교시 12:10~12:50, 5·6학년은 4교시 11:30~12:10 뒤 점심 12:10~12:50. 요일별 교시 수는 1·2학년 화·목·금 5교시(월·수 4교시), 3·4학년 화 6교시(나머지 5교시), 5·6학년 수 5교시(나머지 6교시).
   - 교사·강사·특별실 시간표는 학년마다 시각이 다른 교시를 두 줄로 나눠 시간 순서대로 보여 줍니다(예: `4교시 5·6학년 11:30~12:10` → `4교시 3·4학년 12:10~12:50`). 그 사람이 한 시정만 쓰면 나누지 않습니다.
   - 학년마다 점심이 다르면 교과전담·강사는 점심시간(예: 11:30~12:50) 중 한 시간은 꼭 비어 있게 됩니다. 자동 배치는 처음부터 피하고, 직접 넣거나 옮길 때도 막습니다.
   - 자동 생성·자동 배치는 요일별 교시 수 안에서만 넣습니다. 수업이 없는 칸(빗금)에 직접 넣거나 끌어 옮기면 '○요일 ○교시까지입니다. 넣을까요?' 확인창이 뜹니다.
   - 여러 학년을 맡는 전담 선생님도 **실제 시각**으로 겹침을 검사합니다.
3. 기본설정 → **과목**: 과목 이름·약칭·색, **쓰는 학년**(체크한 학년 시간표에만 그 과목이 보임), **기본 장소**(학급 교실·특별실), ⠿ 끌어서 순서 바꾸기
   기본설정 → **장소**: 특별실 (운동장처럼 여럿이 함께 쓰는 곳은 '동시 사용')
4. 기본설정 → **선생님·인증코드**: '담임 자리 만들기' 후 이름 입력, 교과전담·강사 추가 → 저장하면 인증코드가 자동으로 생김
   - **링크 복사**: 코드가 들어 있는 주소. 받은 선생님은 누르기만 하면 바로 자기 입력 화면(본인에게만 보내세요)
   - 링크로 들어오면 **간단 화면**: 담임은 우리 반, 전담·강사는 내 주간 시간표만 보이고, 다른 반은 '학년별 조회'로만 봅니다(오른쪽 위 '전체 메뉴'로 바꿀 수 있음)
   - **안내문 PDF**: 이름·코드·QR(찍으면 바로 입력 화면)을 잘라서 나눠 주기 / **CSV**: 코드·링크 목록
5. 기본설정 → **교과전담 배정**: 학년마다 전담 과목·담당·주당 시수 → **교담 시간표 자동 배치**(교시 범위, 빈 시간만/다시 배치) → 미리보기에서 칸을 끌어 옮기거나 바꾼 뒤 적용(되돌리기 가능)
   - 교과전담·강사가 넣은 칸에는 과목 이름 옆에 작게 '교과전담'·'강사'가 붙습니다.
   - 교과전담·강사의 **기본 교실**(선생님·인증코드 탭, 또는 선생님이 입력 화면 '내 기본 교실'에서 직접)을 정하면 그 선생님 수업은 그 장소로 들어갑니다. 바꿀 때 이미 넣은 수업도 한 번에 바꿀 수 있습니다(그 시간에 다른 반이 쓰는 특별실이면 건너뜀).
6. 기본설정 → **묶음 수업**: 동아리·선택수업처럼 여러 반 학생을 섞어 여러 선생님·교실로 나누는 시간
7. 기본설정 → 기본 정보 → 입력 순서 **1단계(교과전담·강사 먼저)** → 전담·강사 선생님이 확인·수정
8. 전담 입력이 끝나면 **2단계(모두 입력)** → 담임은 잠긴 전담 칸을 뺀 나머지에 입력
   - 과목을 **끌어다 칸에 놓기**(또는 고르고 누르기), 넣은 칸은 끌어서 옮기기, **넣은 칸끼리 끌어 놓으면 서로 바뀜**
   - 학교 과목에 없는 수업은 **＋ 직접 입력**으로 과목 이름·색을 정해 넣기(예: 생존수영)
   - **✨ 자동 생성**: 담임은 과목별 주당 시수(2시간 연속 묶기 가능), 전담·강사는 과목·학년(반)별 시수·교시 범위를 넣으면 빈 칸에 고르게 생성 → 마음에 안 들면 **🔀 다시 생성하기**(누를 때마다 다른 배치) → 미리 보고 적용·되돌리기
   - **함께 들어가기(협력수업)**: 켜고 다른 선생님 칸을 누르면 한 반에 선생님 둘이 함께 들어감
9. **조회**(학급·학년별·교사·교실·한눈에) / **출력**(학급별·학년별·교사강사별·교실별·전체, A4 가로·세로, PDF·JPG·**엑셀**·인쇄)
   - 출력 **🔍 교담 없는 시간 찾기**: 학년을 고르면(여러 학년도 — 예: 5·6학년을 고르면 두 학년 모든 반이 함께 비는 시간, '학년별 따로'도 가능) 모든 반이 담임 수업인 시간(교담·강사·묶음 수업 없음)을 음영으로 보여 줍니다(PDF·인쇄 가능). 학년 행사 잡을 때 쓰세요.
   - 자동 생성 미리보기에서 칸을 **길게 누르면(PC는 두 번 클릭) 📌 고정** — '다시 생성'해도 그 칸은 그대로 둡니다.
   - 출력 **칸 색**: 과목별 · 학급별 · 선생님·강사별(담임은 회색, 교과전담·강사는 사람마다 다른 색) · 색 없음(흑백). 교사·강사별 출력을 고르면 학급별 색, 학급별 출력을 고르면 과목별 색으로 저절로 바뀝니다. 학급별·선생님별이면 아래에 범례가 붙습니다.
10. 화면 오른쪽 위 **🌓 자동 / ☀️ 주간 / 🌙 야간** 단추로 화면 밝기 바꾸기

새 학교 만들기 단추 자체를 없애려면 `wrangler.jsonc`의 `"ALLOW_NEW_SCHOOL": "true"`를 `"false"`로 바꾸고 다시 배포하세요.

## 운영 도움 기능 (v1.16)
- **↶ 되돌리기**: 입력 화면 오른쪽 위 단추 또는 Ctrl+Z (최근 50번)
- **최근 지운 시간표**: 관리자가 학급·학년·선생님·전체를 지우면 이 기기에 자동 보관 → 관리에서 '되살리기'
- **✓ 점검**(관리자, 조회 탭): 겹침 · 교담 시수 부족 · 점심 없는 날 · 요일 교시 밖 칸 · 교과전담·강사 입력 진행률 · 학급별 채움
- 관리 → **학교관리자 코드**: 지금 코드가 보이고 바로 바꿀 수 있습니다(v1.22 이후 정한 코드부터 보임).
- 교과전담 배정 → **맡는 반** 단추·'나눠 맡기': 한 과목을 반마다 다른 선생님이 맡게 합니다(예: 5-1·5-2 정과학, 5-3 박과학). 자동 배치도 이대로 합니다.
- **보관함**: '다음 학기 준비'를 하면 지금 시간표가 보관함에 들어가 조회 → 🗄 보관함에서 볼 수만 있습니다. 관리 → 보관된 시간표 → '이 시간표로 되돌리기'를 누르면 지금 시간표가 보관되고 예전 시간표를 다시 고칠 수 있습니다(최근 3개).
- **3단계 확정**: 기본 정보 → 입력 순서에서 고르면 모두 잠김(서버에서도 막음). **다음 학기 준비**: 백업 → 학기 이름 바꾸고 1단계로
- 두 관리자가 동시에 기본설정을 고치면, 나중에 저장하는 쪽에 '덮어쓸까요?'를 묻습니다.
- **불가 시간**: 선생님·인증코드 → 교과전담·강사 줄의 '불가' 단추 (출장·연수·겸임). 자동 배치는 피하고, 직접 넣을 땐 한 번 묻습니다.
- **엑셀 시정표 불러오기**: 시정표 메뉴 → '📄 엑셀 시정표 불러오기' (요일 아래 '12학년·34학년·56학년' 칸이 있는 통합 시정표)
- 휴대폰에서 학급 시간표는 월~금을 한 화면에(과목명만 크게), 교사 시간표는 요일 하나씩(위의 요일 단추) 보여 줍니다.

## 실시간 반영
화면을 열어 둔 모든 선생님에게 바뀐 내용이 바로(1초 안쪽) 나타납니다. 와이파이가 잠깐 끊겨도 다시 연결되면서 그동안 바뀐 내용을 받아 옵니다.

## 보안
- 인증코드는 들어올 때 한 번 서버로 보내(HTTPS) **서버에서만** 확인합니다. 확인용으로는 소금을 친 지문(SHA-256)만 씁니다. 관리자가 나눠 줄 코드 목록은 관리자 입장권으로만 볼 수 있습니다.
- 코드가 맞으면 그 기기에 입장권이 생기고, 입장권으로는 **자기 시간표만** 고칠 수 있습니다. 학교 설정·코드 관리·전체 지우기는 관리자 입장권만 됩니다.
- 한 사람에게 틀린 코드를 **15분에 8번** 넣으면 15분 동안 막힙니다(맞는 코드도). 학교 전체(같은 인터넷 주소)는 1시간에 100번까지입니다.
- 코드를 **새로** 만들면 예전 코드로 들어와 있던 기기는 바로 끊깁니다.
- 시간표와 학교 설정은 학교 코드를 아는 사람이면 **볼 수** 있습니다.
- 학기 초·말에는 기본설정 → 관리 → **백업 파일 받기**로 보관해 두세요.

## 무료 한도 (2026년 11월 기준)
Workers 요청 하루 10만 건, Durable Objects 저장 5GB. 한 학교(선생님 50명 안팎)는 넉넉히 들어갑니다. 한도를 넘으면 그날(UTC 기준, 한국 시각 오전 9시에 초기화)은 저장이 실패합니다.

## 날짜별 변경 · 공개 링크 · 변경 기록 (v1.26)
- **조회 → 📅 날짜별**: 관리자가 빠지는 선생님을 고르면 그날 수업과, 그 시간에 비어 있는 선생님만 보강 후보로 보입니다. 자습·수업 없음도 고를 수 있고 '이날 안내 PDF'로 뽑습니다. 기본 시간표는 바뀌지 않습니다(넉 달 지난 기록은 저절로 정리).
- **기본설정 → 관리 → 학생·학부모용 공개 링크**: 학급마다 보기 전용 링크와 QR. 코드 없이 보기만 됩니다.
- **기본설정 → 관리 → 최근 바뀐 시간표**: 누가 언제 몇 칸을 바꿨는지(최근 500건, 서버에 저장). 이 기능을 올린 뒤부터 쌓입니다.
- **선생님 하루 제한**: 선생님 카드의 '하루 ○시간까지'·'연속 ○시간까지'를 자동 배치가 지키고, 점검에 '하루 부담 초과'로 보입니다.

## 버전
